# Make My Marriage

Project scaffold only, using Next.js App Router, TypeScript, Node.js, Mongoose, and Zod.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. No database credentials are needed for the starter page.

Included: a plain starter page, empty domain folders, environment validation, a reusable database connection helper, a health endpoint, and development/check commands. No product screens, authentication, domain models, business APIs, or provider integrations are implemented.

Read the supplied [project documents](docs/README.md) and [local setup](docs/development/LOCAL_SETUP.md).
